# 1対1スマイルスタディ｜業務理解テスト

## このページは何をするもの？

塾講師向けの **業務理解確認テスト** です。スタートボタンを押すと 45問の選択式テストが始まり、**10分のカウントダウン**とともに自動採点まで完結します。

サーバーもインターネット接続も不要。**HTMLファイルをブラウザで開くだけ**で動作します。

---

## まず結論（これで何が確認できる？）

- 欠席・日程変更のルールを正しく把握しているか
- 報告書の締め切りや文字数を覚えているか
- 開閉室作業・体験授業・面談の正しい手順を理解しているか
- 給与・交通費・引継ぎなど細かい運用ルールを身につけているか

---

## 使い方（プログラミング知識ゼロでも大丈夫）

1. このフォルダにある **`index.html`** をダブルクリックする
2. Chrome・Edge・Safari などのブラウザで自動的に開く
3. プライバシーポリシーを確認して **「スタート」** を押す
4. 45問すべてに答える（ページ上部のバーで残り時間が確認できる）
5. **「提出して採点」** を押すと結果と不正解の解説が表示される

> **ポイント：** 結果はこの端末上にのみ表示され、個人情報は一切収集しません。「もう一度受験」ボタンで何度でも挑戦できます。

---

## テストの動作イメージ

```
ブラウザで index.html を開く
    ↓
プライバシーポリシー確認 → スタートボタン
    ↓
45問の選択式テスト（残り時間バー表示）
    ↓
「提出して採点」または時間切れ → 自動採点
    ↓
スコア表示 ＋ 間違えた問題の正解・解説
```

## 問題を追加・修正したいとき

`script.js` の先頭にある `quizData` 配列を編集します。1問あたりの形式は以下の通りです。

```js
{
  q: '【カテゴリ】問題文',
  c: ['選択肢A', '選択肢B', '選択肢C', '選択肢D'],
  answer: 0  // 正解のインデックス（0=A, 1=B, 2=C, 3=D）
}
```

**変更時の注意：**

- `answer` は必ず `0〜3` の数字で指定する（文字列ではなく数値）
- 選択肢 `c` の配列は必ず4つ用意する
- カンマの付け忘れ・多すぎに注意（ブラウザの開発者ツールでエラーを確認できます）

## 技術情報（開発者・管理者向け）

### 使用技術

- **HTML / CSS / JavaScript**（外部ライブラリ・フレームワーク不使用）
- サーバー不要。ブラウザのみで動作（オフライン対応）
- 採点処理はすべてブラウザ内で完結（データの送受信なし）

### 注意事項

#### GitHub Pages で公開する場合

リポジトリ設定の「Pages」から `main` ブランチを選択するだけで公開できます。`index.html` / `style.css` / `script.js` が同じフォルダにある限り、追加設定は不要です。

#### ローカルで開く場合

`index.html` をダブルクリックして開けば動作します。  
ただし、一部のブラウザはローカルファイルへのアクセスを制限することがあります。その場合は Chrome か Edge を使用してください。

#### データの保存について

回答データはブラウザのメモリ上にのみ存在し、ページを閉じると消えます。結果の記録が必要な場合はスクリーンショットを撮ってください。

## つまずいたときの確認ポイント

1. `index.html` と `style.css` と `script.js` が**同じフォルダ**に入っているか
2. ファイルを**ダブルクリック**して開いているか（ドラッグアンドドロップでも可）
3. 画面が崩れている場合は `style.css` が読み込めていない可能性があるため、同じフォルダにあるか確認する
