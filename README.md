# 1対1スマイルスタディ｜業務理解テスト

## このページについて

塾講師向けの **業務理解テスト** です。スタートボタンを押すと 45問の選択式テストが始まり、制限時間 **10分** で自動採点されます。HTMLファイル1つで動くため、サーバーやインターネット接続は不要です。

---

## どんなことができるの？

| 機能 | 内容 |
|------|------|
| 45問の選択式テスト | 4択の問題に画面上で答えられます |
| 10分タイマー | 残り時間がリアルタイムで表示されます |
| 自動採点 | 提出ボタンを押すか時間切れになると即座に採点されます |
| 間違いの解説 | 不正解の問題は正答とともに確認できます |
| 再受験 | 「もう一度受験」ボタンで何度でも挑戦できます |

---

## テストの出題範囲

| カテゴリ | 主な内容 |
|----------|---------|
| 理念・目標 | 教室方針・スタッフ共通の目標 |
| 欠席・日程変更 | 振替ルールの境界・手続きの流れ |
| 報告書 | 締め切り・最低文字数・記載ルール |
| 面談 | 準備内容・担当範囲・資料作成ルール |
| 体験授業 | 当日の流れ・到着推奨時刻・必須対応 |
| 開閉室作業 | オープン・クローズの正しい手順 |
| 給与・交通費 | 締め日・上限額・管理費の扱い |
| その他業務 | シフト確認・引継ぎ・コピー機ルールなど |

---

## 使い方（プログラミング知識ゼロでも大丈夫！）

1. このフォルダにある **`index.html`** をダブルクリックします
2. Chrome・Edge・Safari などのブラウザで自動的に開きます
3. プライバシーポリシーを確認して **「スタート」** ボタンを押します
4. 45問すべてに答えます（ページ上部のバーで残り時間が確認できます）
5. **「提出して採点」** ボタンを押すと結果と解説が表示されます

> **ポイント：** ファイルはインターネット接続なしで使えます。個人情報は一切収集しません。
